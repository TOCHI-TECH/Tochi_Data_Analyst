Project overview

A Python-based data exploration project focused on understanding salary records, checking data types, and answering practical pay-related questions from a CSV dataset.

Business / analysis question

What does the salary dataset tell us about average pay and overtime pay, and what data-quality issues should be checked before drawing conclusions?

Tools used

Python · Pandas · Jupyter Notebook · Exploratory Data Analysis

The exact tools and steps should reflect the final submitted notebook or analysis files.

Analysis workflow

  • Load the CSV carefully and inspect its shape, columns, and data types.
  • Check missing values, inconsistent formats, and mixed-type columns before calculating statistics.
  • Calculate average pay and identify the record with the highest overtime pay, using the dataset’s actual column definitions.
  • Summarize the findings and note any limitations in the data.

Deliverables

  • A documented cleaning and exploration workflow.
  • Verified summary statistics tied to the source dataset.
  • A concise explanation of what the results can—and cannot—tell us.
Results and numerical findings should be added after checking the actual dataset and analysis output. This page intentionally does not invent statistics or conclusions.
