Project overview

A machine-learning coursework project using a dataset with more than 300 rows, with preprocessing for missing values and categorical variables, followed by model evaluation and assumption checks.

Business / analysis question

How well can a set of explanatory variables predict a numeric outcome, and how reliable are the model’s assumptions?

Tools used

Python · Pandas · NumPy · scikit-learn · Regression Diagnostics

The exact tools and steps should reflect the final submitted notebook or analysis files.

Analysis workflow

  • Inspect the target and predictor variables and handle missing data appropriately.
  • Encode categorical variables without leaking information from the test set.
  • Split the data into training and test sets and fit a multiple linear regression model.
  • Evaluate predictions with suitable metrics and inspect residuals for linearity, independence, homoscedasticity, and approximate normality.

Deliverables

  • A repeatable preprocessing and modeling pipeline.
  • Evaluation metrics calculated from the held-out test set.
  • Residual diagnostics and a balanced explanation of model limitations.
